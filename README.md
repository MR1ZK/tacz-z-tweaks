# TACZ: Z-Tweaks（TACZ：改装UI调整）

## 这是什么

面向 Minecraft Forge 1.20.1 的 [TACZ](https://github.com/MCModderAnchor/TACZ)（Timeless & Classics Guns）客户端附属模组，接管 TACZ 自带的改装界面（默认 Z 键）。

预览可以拖着转、滚轮缩放，鼠标划过候选配件就在 3D 里先装上看看效果，详情条整条跟着那一件走（连带参数变化列）。候选列表只列当前槽位装得上的配件，双击即装；装不上的（手里有、但这把枪不吃）置底分组并写清原因。装上去是变好还是变差不用自己算，Pros / Cons 双栏直接写出来。一套装配可以存成预设一键套用，也能导出分享码发给别人。

| 能力 | 说明 |
|---|---|
| 界面接管 | 按键、其它模组、服务端刷新打开原生界面的入口，全部转到 Z-Tweaks 界面 |
| 轨道相机 | 左键左右拖环绕、上下拖绕枪械自身长轴滚转，枢轴取根骨骼所以贴在枪身上；右键拖平移，滚轮缩放，可以转满圈 |
| 悬停虚拟装配 | 鼠标划过候选列表，预览里就装上那个配件。克隆枪栈驱动渲染，不落 NBT 也不发 packet，先看效果再决定装不装 |
| 悬停驱动详情条 | 鼠标划过哪一件，详情条整条就跟到哪一件——名字+描述、Pros / Cons、参数变化列一起换，并标出「预览：\<件名\>（未安装）」；移出列表立刻回到选中的那一件。整条只在悬停行真的变了时才重算 |
| Pros / Cons | 由属性修改器自动推导增减，绿 / 红双栏直读。`DELTA` 模式算"装上后会变成什么样"，`TACZ_TEXT` 模式直接复用 TACZ 的成品文本 |
| 候选列表 | 只列当前槽位装得上的配件，可搜索、可按名称或模组排序。生存模式只看背包里有的，创造模式列全部并把没带在身上的图标盖灰；**真能装上的配件永远置顶**，优先级高于玩家选的排序方式 |
| 不可安装的配件 | 手里有、但这把枪装不上的配件不再凭空消失：置底分组、灰显、上面压一条分隔线，右侧文字角标说清原因——「装不上这个配件」（枪的白名单不含它）/「这里装不了配件」（枪压根没声明白名单）。它们可选中、可看名字与描述，但不驱动 3D 预览与参数，双击 / 安装按钮一律拒绝并说明，不会出现"响了音效、弹了已安装、枪上其实什么都没有" |
| 按参数排序 | 排序项不止名称和模组：开镜时间、后坐力、射速、重量、有效射程、弹速、护甲穿透、穿透、击退、爆头倍率，共十个。方向按"优→劣"而不是数值大小，所以"后坐力 优→劣"直接就是后坐力最小的在前；"只看改善的"能筛掉不如现在装着的那些 |
| 参数与变化列 | 概览态参数卡分三列：名字+描述 / 参数（口径、经验等级、枪种、伤害、护甲穿透、爆头伤害、移动速度、开火模式、弹匣容量、射速、弹速、穿透、开镜时间）/ 变化项。第二列是当前值，第三列只列"装上正在看的那个配件之后会变的项"，给绝对双值（`12.5 → 14.2`）并按好坏染色，顺序固定、列内可滚 |
| 概览态 | 没选槽位时不画候选框、不画搜索框和排序按钮，那块区域交还给预览的拖拽和缩放；详情条整条拿来放枪械参数卡 |
| 预设 | 一份预设只记「槽位 → 配件 id」，按枪 id 存在 `<游戏目录>/ztweaks/`（多人切到 `servers/<主机名>/`，两侧结构一致）。应用前先干跑一次，把「装上 / 卸下 / 缺件」和背包空位摆出来再确认；**预设没提到的槽位按"就是要空"处理**，所以同一份预设在任何起点应用结果一致。列表在详情条的"预设"按钮里：左键应用、右键删除；分享码走剪贴板（带前缀的 Base64(GZip(json))），导入会先校验枪 id 再让你确认 |

界面布局参考了 Garry's Mod 的 ARC-9。

操作按键表见 `docs/controls.md`，配置项见 `docs/config.md`。术语表在 `CONTEXT.md`，架构决策记录在 `docs/adr/`，架构笔记在 `docs/session-context.md`。

**接下来要做什么、以及为什么那样做，看 [路线图](https://github.com/MR1ZK/tacz-z-tweaks/issues/1)**——那是一次寻路留下的决策地图，每个待做功能都有一张票承载它的决策与依赖。地图**已归档**（16 张子票全部有结论：12 解决 / 3 推迟 / 1 否决），**已解决的决策仍然有效**；推迟的三张是 TACZ 版本下限与兼容策略、内部 API 适配层（compat/）、一键拆空。开工前的规划稿归档在 `docs/refit-plus-plan.md`（已标注哪几节作废），三份源码调研在 `docs/research/`。

## 怎么安装

装好 Forge 1.20.1，把 TACZ 本体和本模组的 jar 一起丢进 `.minecraft/mods/`。纯客户端，装在自己机器上就行，服务端不用管。

TACZ 需要 **1.1.4 及以上**，这是 `src/main/resources/META-INF/mods.toml` 声明的范围。实际只按 `1.1.8-hotfix` 编译和试玩过，更早的版本没冒烟：万一那边改了注入目标的方法签名，注入会静默降级，界面照常但相机和虚拟装配失效。

## 构建

1. 取得 TACZ 本体 jar：在相邻仓库构建 `cd ../TACZ && ./gradlew build`，取 `build/libs/` 产物；或从 CurseForge / Modrinth 下载。
2. 把 jar 放进 `libs/`，文件名照 `gradle.properties` 里的 `tacz_version` 来。
3. 构建本模组：

```bash
./gradlew build          # 产物在 build/libs/
./gradlew runClient      # 启动开发客户端（需要 libs/ 中存在 TACZ jar）
```
