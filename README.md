# TACZ: Z-Tweaks（TACZ：改装UI调整）

这是一个面向 Minecraft **1.21.1（NeoForge）** 的 [TACZ](https://github.com/MCModderAnchor/TACZ) 客户端附属模组：把它自带的改装界面换成更好用的一套 —— 对着枪按 **Z**，打开的就是 Z-Tweaks 界面。（1.20.1 Forge 版本继续维护在 `main` 分支，见 v0.4.2。）

## 它能帮你做什么

原版改装界面不是不能用，只是看枪、比配件都费劲。这个模组想把这些事变得直观点：

- **转着看枪**：左键拖动绕着枪转，上下拖是让枪自己滚起来，右键拖动平移，滚轮缩放 —— 想看哪一面就看哪一面。
- **先"装上"看看再决定**：鼠标划过配件列表，3D 预览里立刻装上那一件。这只是预览，不会动你的枪。
- **说明跟着鼠标走**：划过哪一件，下面整条说明就换成哪一件 —— 名字、描述、优缺点、装上之后参数会怎么变。
- **装上是好是坏不用自己算**：每个配件自动列出优点和缺点；正在看的那一件，还会单独列出"装上它以后哪几项参数变了、从多少变成多少"。
- **列表里只放这把枪能用的配件**：可以搜，可以按名字、模组或十种参数排序（排序方向是"好 → 坏"，比如选"后坐力 优 → 劣"，后坐力最小的就在最前）。"只看改善的"能把不如现在装着的那些筛掉；真能装上的永远排在最前面。
- **装不上的会告诉你为什么**：手里有、但这把枪装不上的配件不会凭空消失，而是沉到列表底部、灰掉并在右边写清原因（「装不上这个配件」／「这里装不了配件」）。它们能选中看描述，但装不了 —— 不会出现"响了一声、提示已安装、枪上却什么都没有"。
- **一套装配存下来一键套用**：把当前装配存成预设，之后一键装回去；也能生成一段分享码发给朋友，对方导入就能用同一套。应用之前会把"装哪几件、卸哪几件、缺哪几件"先列给你确认。
- **一把枪的参数一眼看全**：没选槽位时，显示这把枪本身的参数（伤害、射速、后坐力、开镜时间……），可滚动。
- **换外观**：左上角「预设」旁边那颗按钮可在四套主题间切换 —— 默认（TACZ 青）/ MD3 质感 / 千禧航空 / Win 经典，点一下立即生效；默认主题还能自己改强调色（输 `#RRGGBB`，边输边预览）。配置屏里也有同一行。四套不只是换色：面板的渐变 / 银灰浮雕 / 玻璃高光、按钮的受光面、弹层投影与分栏引导线都跟着主题走；MD3 与千禧航空还各带一层氛围粒子（微粒 / 流光），可在配置里调成 `REDUCED` 或 `OFF`。

## 安装

1. 装好 **NeoForge 21.1.x（Minecraft 1.21.1）**。
2. 把 **TACZ NeoForge 1.21.1 本体**和本模组的 jar 一起放进 `mods/` 文件夹。
3. 进游戏，对着枪按 **Z**。

本模组只需要装在自己这边：服务器上照旧装它的 TACZ 就行，不需要为本模组做任何改动，多人游戏里照常用。

## 版本要求

- Minecraft **1.21.1** + NeoForge **21.1.x**
- TACZ **1.2.0 及以上**（NeoForge 1.21.1 构建）；本版在 **1.2.0-hotfix** 上编译和试玩
- 1.20.1 Forge 版本见 `main` 分支的 **v0.4.2**
- 可选：装了 **TACZ Addon** 并开着它的「随意配件」时，本模组会自动适配 —— 那种情况下装配件不再要求"手上有实物"（这把枪仍然只接受它认的配件）

## 自己构建

1. 先把 **TACZ NeoForge 1.21.1** 的 jar 放进 `libs/`，文件名照 `gradle.properties` 里的 `tacz_version` 来（例如 `tacz-neoforge-1.21.1-1.2.0-hotfix.jar`）。
2. 然后：

```bash
./gradlew build      # 产物在 build/libs/
./gradlew runClient  # 起一个开发用客户端（run/client）
```

Windows 上也可以直接双击 `verify-client.bat`：先构建、再起开发客户端，关掉游戏后自动扫 `run/client/logs/latest.log` 里的 `at com.ztweaks` 异常。`verify-client.bat --check` 只查依赖不启动，`--skip-build` 跳过构建。
