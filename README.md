# TACZ: Z-Tweaks

给 Minecraft 1.20.1（Forge）上的 [TACZ](https://github.com/MCModderAnchor/TACZ) 换一套改装界面：对着枪按 **Z**，打开的是 Z-Tweaks 的界面，而不是原来那一套。界面参考了 Garry's Mod 的 ARC-9。

## 它能帮你做什么

原版改装界面不是不能用，只是看枪、比配件都费劲。这个模组想把这些事变得直观点：

- **转着看枪**：左键拖动绕着枪转，上下拖是让枪自己滚起来，右键拖动平移，滚轮缩放 —— 想看哪一面就看哪一面。
- **先"装上"看看再决定**：鼠标划过配件列表，3D 预览里立刻装上那一件。这只是预览，不会动你的枪。
- **说明跟着鼠标走**：划过哪一件，下面整条说明就换成哪一件 —— 名字、描述、优缺点、装上之后参数会怎么变。
- **装上是好是坏不用自己算**：每个配件自动列出优点和缺点；正在看的那一件，还会单独列出"装上它以后哪几项参数变了、从多少变成多少"。
- **列表里只放这把枪能用的配件**：可以搜，可以按名字、模组或十种参数排序（排序方向是"好 → 坏"，比如选"后坐力 优 → 劣"，后坐力最小的就在最前）。"只看改善的"能把不如现在装着的那些筛掉；真能装上的永远排在最前面。
- **装不上的会告诉你为什么**：手里有、但这把枪装不上的配件不会凭空消失，而是沉到列表底部、灰掉并在右边写清原因（「装不上这个配件」／「这里装不了配件」）。它们能选中看描述，但装不了 —— 不会出现"响了一声、提示已安装、枪上却什么都没有"。
- **一套装配存下来一键套用**：把当前装配存成预设，之后一键装回去；也能生成一段分享码发给朋友，对方导入就能用同一套。应用之前会把"装哪几件、卸哪几件、缺哪几件"先列给你确认。
- **一把枪的参数一眼看全**：没选槽位时，显示这把枪本身的参数（伤害、射速、后坐力、开镜时间……），可滚动。

## 安装

1. 装好 **Forge 1.20.1**。
2. 把 **TACZ** 本体和本模组的 jar 一起放进 `mods/` 文件夹。
3. 进游戏，对着枪按 **Z**。

本模组只需要装在自己这边：服务器上照旧装它的 TACZ 就行，不需要为本模组做任何改动，多人游戏里照常用。

## 版本要求

- Minecraft **1.20.1** + Forge **47.3.x**
- TACZ **1.1.4 及以上**（实际只在 1.1.8-hotfix 上编译和试玩过。如果哪天 TACZ 改了内部结构，界面仍然能打开，但转视角和预览这类功能可能失灵 —— 遇到怪问题先核对版本）
- 可选：装了 **TACZ Addon** 并开着它的「随意配件」时，本模组会自动适配 —— 那种情况下装配件不再要求"手上有实物"（这把枪仍然只接受它认的配件）

## 自己构建

1. 先把 TACZ 本体 jar 放进 `libs/`（文件名照 `gradle.properties` 里的 `tacz_version` 来）。
2. 然后：

```bash
./gradlew build      # 产物在 build/libs/
./gradlew runClient  # 起一个开发用客户端
```
