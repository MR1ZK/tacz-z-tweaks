# 操作

改装界面默认 `Z` 键打开（和原生一样）。按键、其它模组、服务端刷新打开原生界面的入口都会被转到这个界面。

| 输入 | 作用 |
|---|---|
| 左键拖 | 左右=环绕，上下=绕枪管长轴滚转（一屏 360°） |
| 右键拖 | 平移（只挪位置，不改朝向） |
| 滚轮 | 缩放（向上推=拉近） |
| 中键 / `R` | 相机复位（角度、缩放、平移一起清零） |
| `1`–`6` / 左键点槽位 | 选槽位（同一槽位再点一次退回概览态） |
| 右键点槽位 | 直接卸下该槽位上的配件，省掉"选槽位 → 点卸下"两步 |
| `↑` `↓` | 切换候选配件 |
| 双击候选行 | 直接装上该配件 |
| `Enter` / `U` | 安装 / 卸下 |
| 点排序按钮 | 展开排序/筛选层（在搜索框右侧）：名称、模组、十个配件参数，方向，以及"只看改善的" |
| `Esc` | 关闭 |

滚轮的作用看指针落在哪：排序层展开时落在层上就滚层自己（GUI 高度不够时层里的十四行放不下）；候选框内（搜索框和排序按钮除外）翻列表；概览态落在详情条上就滚指针所在的那一列，三列各自独立；选中配件时落在左列滚描述；其余情况缩放相机。

右键点空槽位会提示；槽位条以外的空白处右键仍然是平移。概览态不画候选框、搜索框、排序按钮和安装/卸下按钮。

搜索框按显示名过滤，切槽位时清空；排序偏好在切槽位时保留。

排序层里的参数排序按"优劣"而不是数值：`开镜时间 优→劣` 排出来的是开镜最快的在最前，`后坐力 优→劣` 则是后坐力最小（对着当前已装的配件比）的在前。方向开关对名称/模组这两项就是 A-Z / Z-A。"只看改善的"是筛选，只在选中某个参数时可用——它砍掉"不如现在装着的那个"的候选。对该参数没有任何改动的配件算"无改动"，排在改善的与变差的之间，既不会沉底也不会被筛掉。

排序值是在列表重建时算的（切槽位、改搜索、改排序各一次），不是每帧——每个候选都要克隆一次枪栈跑一遍 TACZ 的属性求值，代价不低。

`V` 和 `G` 默认关着，要在配置文件里先打开：`V` 切换相机开关，方便和原生取景对照；`G` 叠加原生属性条。
