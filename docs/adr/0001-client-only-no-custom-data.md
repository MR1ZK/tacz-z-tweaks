# v1 是纯客户端模组：不引入自定义数据与网络同步

我们原本计划引入附属自己的"扩展元数据"（分类文件夹、手写优缺点、单位覆盖、背景资料），并由自建网络通道同步到客户端。事实核查后放弃了这一层：TACZ 的每个属性修改器都提供 `getPropertyDiagramsData(gunItem, gunData, cacheProperty)`，其 `DiagramsData` 已包含**基准占比、修改量、好坏方向（`positivelyBetter`）与本地化文案**，且纯客户端可调用；分类也可直接复用 `AttachmentType` 与 TACZ 标签体系。因此 v1 决定**不引入任何附属自定义数据、不自建网络通道、不要求服务端安装**，全部功能为客户端行为，数据源限于 TACZ 已同步的 common 数据与 ItemStack NBT。

## Consequences

- 模组可加入任何已装 TACZ 的服务器（含陌生服务器），无需服务端配合，也不存在"服务端版本不一致"的同步问题。
- 无法为个别配件定制分类文件夹、手写优缺点、单位覆盖与背景资料；描述文案只能沿用 TACZ 原生 tooltip key。这些是 v1.1 的入口，届时才需要引入同步通道。
- 属性文案的单位与舍入由 TACZ 决定（单位只存在于其拼好的字符串里，字段中不携带），本项目无法改写。
